=== HƯỚNG DẪN ĐẶT FILE ÂM THANH ===

Đặt các file .wav vào THƯ MỤC NÀY:
  src/main/resources/com/wildlife/sound/

Tên file yêu cầu (định dạng .wav khuyên dùng):
  hunt.wav      — tiếng gầm/hú khi phát hiện con mồi
  eat.wav       — tiếng ăn, nhai
  death.wav     — tiếng chết (tiếng kêu ngắn)
  drink.wav     — tiếng uống nước (tiếng nước chảy)
  flee.wav      — tiếng chạy trốn (tiếng bước chân nhanh)
  season.wav    — tiếng chuyển mùa (tiếng chuông, tiếng gió)
  ambient.wav   — tiếng nền (tiếng chim, gió, côn trùng)

Nếu thiếu file → game vẫn chạy bình thường, không có âm thanh.

Nguồn tải miễn phí:
  https://freesound.org
  https://pixabay.com/sound-effects/
